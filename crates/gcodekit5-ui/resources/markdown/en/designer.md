# Designer
The Designer tool is used to create, edit, and import vector designs, as well as import images for engraving.

## Main Actions
- Draw primitives (rectangles, circles, lines, ellipses, polylines, triangles, polygons, pinions, gears)
- Add text
- Add images and even create a composition of several images with vector objects
- Define engraving parameters independently for each image using its properties
- Define global parameters for vector objects that do not require independent parameters
- Define parameters independently for each vector object using its properties
- Reorder objects in the Objects panel, which will be used for G-code generation
- Import DXF and SVG files
- Out of Bounds warning If any point goes outside the workspace, an Out of Bounds warning will appear in the G-code so the user can determine what to do.
- Export to G-code or SVG
